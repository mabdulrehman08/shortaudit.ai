# ShortAudit AI

Demo-ready short-form audit app for creators. The root Next.js app lets you upload a video or use a sample short, then generates a polished report with viral score, retention forecast, hook rewrites, timeline risks, caption ideas, and ranked fixes.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Optional env:

```env
OPENAI_API_KEY=
BLOB_READ_WRITE_TOKEN=
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

The demo still works without provider keys.
